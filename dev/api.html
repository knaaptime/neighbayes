    API reference¶

    Models¶

    A model class names a process and a family: SAR, SARLogit, SARNegBinFlow. Panel structure, effects, dynamics, and the flow restriction are arguments to the same class:

    • time_col (formula mode) or T (matrix mode) makes the model a panel;

    • unit_effects (pair_effects for flows) is None, "fixed", or "random", and time_effects=True adds fixed time effects;

    • dynamic=True adds the time lag \(y_{t-1}\), and dynamic="restricted" gives the restricted dynamic SDM;

    • separable=True pins \(\rho_w = -\rho_o \rho_d\) in a flow model.

    A combination the package does not implement raises when the model is constructed.

    Data Generating Processes¶

    Note

    The cross-sectional and (scalar) panel DGP simulators accept W (Graph/sparse/dense) and gdf inputs. You may provide both together; in that case W is used for simulation and is checked against gdf for dimensional compatibility (a ValueError is raised when they do not describe the same number of spatial units).

    The flow DGPs below take G (libpysal Graph), gdf, n, and knn_k instead. All four are optional: when none is supplied the DGP synthesises a point grid via synth_point_geodataframe() and builds a row-standardised KNN graph automatically.

    Each simulator draws from the model class it is named for and takes the same design arguments: T (with N) for a panel, unit_effects and time_effects (scaled by unit_effect_sd and time_effect_sd, default 0.5), and dynamic. Fixed and random unit effects draw the same data; the distinction belongs to the model.

    simulate_ols([n_side, W, gdf, beta, sigma, ...])

    Flow Data Generating Processes¶

    Each flow DGP accepts n, G, gdf, and knn_k as optional arguments and (unless gamma_dist=0.0) appends a log_distance column log(1 + d_{ij}) with default coefficient gamma_dist=-0.5.

    Each flow simulator takes separable, T, pair_effects, and time_effects as its model class does. The Gaussian flow DGPs (simulate_sar_flow and simulate_sem_flow) default to distribution="lognormal", returning strictly-positive flows y = exp(eta) where eta is the latent SAR-filtered linear predictor (also exposed in the result dict as "eta_vec" / "eta"). Pass distribution="normal" to recover the legacy Gaussian-on-y behaviour. The Gaussian-likelihood flow models in neighbayes.models.flow operate on the latent scale, so fit on np.log(y) to recover the SAR parameters. The Negative Binomial DGPs are unchanged.

    Runtime Configuration¶

    Opt-in helpers that change how fits run, not what they estimate: a persistent compile cache, and on-disk checkpoints that let a long JAX Gibbs fit resume after a crash with the draws it would have returned uninterrupted.

    checkpoints(path, *[, every])

    Save long JAX Gibbs fits to disk as they run, and resume them after a crash.

    enable_compile_cache([path])

    Enable persistent on-disk compile caches for JAX and PyTensor.
